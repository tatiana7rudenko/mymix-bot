# AnimatedVideoPortrait — круглый видеопортрет

Переиспользуемый React-компонент: круглое видео в правом верхнем углу с
премиальной spring-анимацией появления (Motion for React), лёгким «парением»,
свечением, орбитальными линиями и переключателем звука.

## Запуск

```bash
cd web
npm install
npm run dev      # http://localhost:5173
npm run build    # production-сборка в dist/
```

## Как подставить своё видео

1. Скопируйте ваш файл (например, из `C:\Users\Tanya\Claude\Projects\REEL_EDIT\Новая папка`)
   в `web/public/video/`, например как `portrait.mp4`.
2. В `src/App.tsx` поменяйте `src="/video/portrait-placeholder.mp4"`
   на `src="/video/portrait.mp4"`.
3. Настройте `framePosition` под реальное положение лица (см. ниже).

Сейчас в проекте лежит сгенерированная заглушка
`public/video/portrait-placeholder.mp4` (вертикальная 9:16, «лицо» в верхней
трети) — просто чтобы демо работало из коробки.

## Как подобрать framePosition (не центрируйте вслепую!)

`framePosition` — это CSS `object-position` видео внутри круга.
Круг квадратный, видео обычно вертикальное (9:16), поэтому при
`object-fit: cover` обрезаются верх и низ кадра. Ориентиры:

| Где лицо в кадре                  | framePosition     |
| --------------------------------- | ----------------- |
| Верхняя треть (типичный рилс)     | `50% 22%`–`50% 30%` |
| Центр кадра                       | `50% 40%`         |
| Человек смещён влево              | `38% 28%`         |
| Человек смещён вправо             | `62% 28%`         |

Проверяйте на глаз в dev-режиме: голова не должна обрезаться, должны быть
видны лицо, плечи и немного фона над головой.

## Параметры компонента

```tsx
<AnimatedVideoPortrait
  src="/video/portrait.mp4"        // путь к видео (обязательный)
  poster="/video/poster.jpg"       // постер (опционально)
  framePosition="50% 28%"          // object-position по положению лица
  size={260}                       // диаметр на десктопе, px (220–280)
  sizeTablet={200}                 // необязательно, по умолчанию ~0.78·size
  sizeMobile={140}                 // необязательно, по умолчанию ~0.54·size
  ringColor="linear-gradient(...)" // цвет/градиент тонкой рамки
  glow={true}                      // мягкое свечение позади круга
  glowColor="rgba(206,154,120,.4)" // цвет свечения
  decorations={true}               // орбиты, частицы, градиент, линия
/>
```

Цвета рамки, свечения и декора подобраны под тёплую нейтральную гамму
демо-страницы; при интеграции возьмите 2–3 доминирующих цвета из самого
видео (фон, тон кожи/одежды) и передайте их через `ringColor` / `glowColor`.

## Что уже учтено

- `autoplay muted loop playsinline` + программный `video.muted = true`
  (обязательное условие автозапуска на iPhone/Android);
- звук включается только по клику, кнопка с `aria-label` появляется при
  наведении/фокусе (на тач-устройствах видна всегда);
- `prefers-reduced-motion`: появление сокращается до fade, парение,
  пульсация свечения, орбиты и частицы отключаются;
- анимируются только `transform` и `opacity`, тяжёлых blur нет
  (один маленький `backdrop-filter` на кнопке звука);
- круг позиционирован абсолютно — нулевой layout shift;
- safe area iPhone: отступы через `env(safe-area-inset-*)`,
  `viewport-fit=cover` в `index.html`;
- `overflow-x: clip` на странице — горизонтальный скролл невозможен
  даже на 320 px;
- если видео не загрузилось, показывается градиентная заглушка.
